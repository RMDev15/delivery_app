# Projeto Delivery - Angular & Supabase

Aplicação completa de delivery desenvolvida em Angular, integrada ao Supabase e conectada à API de demonstração (`https://apifakedelivery.vercel.app`).

## Como rodar o projeto:
1. Abra a pasta no VS Code.
2. No terminal integrado, execute:
   ```bash
   npm install
   npm start
   ```
3. Acesse `http://localhost:4200` no seu navegador.
